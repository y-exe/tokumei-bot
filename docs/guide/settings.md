## 設定の適用範囲

Bot管理者（ユーザーID `483307286513582090`）は、管理ロールやサーバー管理権限なしで全管理操作を利用できます。Bot自身に必要なDiscord権限は別途必要です。

- `/settings scope:guild`：サーバー標準。
- `/settings scope:channel`：このチャンネルの上書き。省略時はこちら。
- チャンネルで上書きしていない項目は、サーバー標準を継承。

変更中は下書きです。「保存して反映」で公開します。
案内の色は「タイトル・説明」の色欄を空欄、または「なし」にすると解除できます。
「前の設定を読み込む」は復元候補の読み込み、「標準に戻す」はチャンネル上書きの解除です。

## 変更できる項目

| 設定画面 | 内容 |
| --- | --- |
| タイトル・説明／画像・サムネイル | 見出し、説明、色、画像、フッター |
| ボタン設定 | 投稿・画像・URL・ヘルプの名前、色、絵文字 |
| 表示・再送 | 投稿後の案内再送、URLボタン、保存期間等の表示、URLボタン名の自動表示 |
| 投稿できる内容 | 文章、直接添付、URL取得、説明文の許可 |
| URL変換するサイト | 対応9種類から選択。[一覧](media.md) |
| ルール | 本文、詳細ルールのURL |
| 枚数・制限 | 現在の画面では投稿間隔と通報通知人数を設定 |
| 匿名ID・保存期間 | ID表示、連続投稿のID保持時間、投稿・通報の保存期間 |
| 画像・動画の安全設定 | NSFW・NSFLを個別に許可。未選択は拒否 |
| 管理・投稿ロール | 管理ロール、投稿ロール、通報先、処置ログ先、通常投稿の許可 |
| 禁止語・ドメイン | 1行に1つ。禁止ドメインはサブドメインにも適用 |
| 書き出し／読み込み | 設定JSONの共有。Webhookなどの秘密情報は含めない |

## 主な初期値

| 項目 | 初期値・範囲 |
| --- | --- |
| 匿名ID | 表示、連続投稿の保持20分。保持時間は0〜1440分 |
| 投稿間隔 | 5秒。0〜3600秒 |
| 通報通知 | 異なる通報者3人。1〜50人 |
| 投稿・通報の保存 | どちらも無期限 |
| NSFW・NSFL | どちらも拒否 |
| 通常投稿 | 匿名要望は許可、ほかの初期モードは削除・DM警告 |

## 保存期間

| 設定値 | 動作 |
| --- | --- |
| `0` | 保存しない。既存の対象ログも削除 |
| 日数 | 投稿1〜90日、通報1〜180日 |
| `無期限` | 自動で期限切れにしない |

保存0では、本人編集・削除・通報・投稿者照会など、履歴が必要な機能は使えません。
DBのログ削除ではDiscord上の投稿やバックアップは削除されません。

## 設定JSON

```json
{
  "version": 1,
  "settings": {
    "content": { "allowNsfw": true },
    "policy": { "cooldown": 10 }
  }
}
```

区分は `panel`・`content`・`identity`・`policy`・`moderation` です。
項目と許容範囲の定義は [config.ts](../../src/domain/config.ts) にあります。
`content.animation`・`video`・`maxFiles`・`maxFileMB` は保存形式にありますが、現在の投稿制限には使われていません。
実際の取得制限は[画像・動画の取得](media.md)を参照してください。

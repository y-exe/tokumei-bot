# 設定

[目次](../README.md)

## 設定の適用範囲

Bot管理者は`BOT_ADMIN_ID_URL`で設定したHTTPS URLが返すDiscordユーザーIDです。取得先はプレーンテキストでIDを1件だけ返す必要があります。起動時に取得し、その後1分ごとに更新するため、ID変更に再起動は不要です。取得したIDの有効期限は2分で、取得失敗が続くと運営者権限を停止します。設定済みURLから初回取得できない場合は起動を止め、URL未設定なら運営者権限なしで動作します。サーバーのロールやBotのアプリ所有者から自動判定するものではありません。

| 操作 | Bot管理者 | サーバー管理権限あり | 設定された管理ロール |
| --- | --- | --- | --- |
| チャンネル設定・設置・停止・通報対応 | 可 | 可 | そのロールを許可したチャンネルのみ |
| サーバー標準の変更・そのサーバーのエラー詳細 | 可 | 可 | 不可 |
| 投稿ロール制限の免除 | あり | なし | なし |
| 最短投稿間隔・連投対策の免除 | なし | なし | なし |
| 通常投稿の自動削除を免除 | あり | あり | あり |
| BAN・タイムアウト | 操作者のDiscord権限・ロール順位の確認を免除 | 必要な処罰権限・ロール順位も確認 | 必要な処罰権限・ロール順位も確認 |

**Bot管理者も全制限を迂回できるわけではありません。** 禁止語・禁止ドメイン、NSFW／NSFL、投稿形式、最短投稿間隔、利用停止は適用されます。他人の本人編集・下書き操作、保存0や期限切れの投稿者復元、操作中のサーバーをまたぐ情報参照、内部URLへのアクセスもできません。Bot自身のDiscord権限・ロール順位・送信上限も共通です。

匿名lookupはDiscordの管理権限とは別で、Tailscaleの許可アカウントからのみ利用できます。通報画面には本文・報告者・元投稿へのリンクが表示され、投稿者の実IDは直接表示しません。処罰時は保存中の投稿者情報を内部で使用します。管理ロールの委任先にも通報内容と報告者が見えます。

- `/settings scope:guild`：サーバー標準。
- `/settings scope:channel`：このチャンネルの上書き。省略時はこちら。
- チャンネルで上書きしていない項目は、サーバー標準を継承。

変更中は下書きです。「保存して反映」で公開します。
上部に公開案内のプレビューがあります。1行目にタイトル・説明、画像・サムネイル、ボタン設定、管理・投稿ロール、2行目にルール、画像・動画の安全設定、禁止語・ドメイン、その他があります。書き出し・読み込みは下部です。

「その他」では、説明の右のボタンから投稿間隔・通報、連投対策、匿名ID・保存期間、匿名投稿の利用停止、表示・再送、設定バックアップを開けます。利用停止はどのチャンネルでも有効にでき、通報から対象チャンネルだけ停止します。解除はユーザーIDを指定して行います。次の自動処理もオン・オフできます。

- **URLの不要な情報**：本文・出典・URL取得から、全サイト共通の既知の計測パラメーター（`utm_*`、`gclid`等）とX投稿の共有情報を除去。初期値はオン。検索条件・画像形式・既知の署名付きURLは維持し、他サイトの`a`・`s`を一律には消しません。
- **投稿番号の自動リンク**：本文の`>>番号`を保存済み投稿のリンクに変換。初期値はオン。投稿ログを保存しないチャンネルでは変換しません。
案内の色は初期値では「なし」です。「タイトル・説明」の色欄から変更でき、空欄または「なし」で解除できます。
テキスト・アナウンスチャンネル、スレッド、フォーラム内の投稿に設置できます。スレッドはその中で `/setup` を実行し、Botに「スレッドでメッセージを送信」と親チャンネルの「Webhook管理」を付与してください。非公開スレッドではBotの参加または閲覧できる権限も必要です。
「設定バックアップ」は保存から60日間、件数制限なしで保持します。保存して反映するたびに追加し、保存から60日以上たったものを自動削除します。一覧は25件ずつ表示し、保存元のチャンネル名と日時から選べます。プレビュー・下書きへの読み込み・手動削除には保存元の管理権限が必要で、手動削除には確認が入ります。「保存して反映」までは公開設定を変えません。
「標準に戻す」はチャンネル上書きの解除です。「標準に戻す」「初期値に戻す」も確認画面を経て下書きを変更します。

## 停止後の再開・設定の再利用

`/stop` は受付だけを停止し、設定は残します。`/setup` で保存済み設定が見つかると、使うかどうかを確認します。
停止中の案内を「埋め込みを編集」で開くと再開確認が出ます。編集後に「保存して再開」を押すまで停止状態を保ちます。
このチャンネルの設定、または同じサーバーの別・削除済みチャンネルを選び、プレビューから「この設定で設置」で反映できます。「編集して使う」「新しく設定する」も選べます。
設定だけをコピーし、投稿履歴・投稿者情報・Webhookはコピーしません。別チャンネルの設定は、その設定を管理できる人だけが利用できます。以前から削除されていて名前を記録できていない候補は、IDと案内タイトルで表示します。

## 変更できる項目

| 設定画面 | 内容 |
| --- | --- |
| タイトル・説明／画像・サムネイル | 見出し、説明、色、画像、フッター |
| ボタン設定 | 投稿・画像・URL・ヘルプの名前、色、絵文字 |
| 表示・再送 | 投稿後の案内再送、URLボタン名をSNS名に合わせるか固定名を使うか |
| 追加したい機能 | 文章、直接添付、URL取得をそれぞれ単独で許可。「画像に説明文を加えない」を選択した場合だけ説明文を禁止。URLボタンの表示はURL取得の選択に連動 |
| URL取得 → 送信できるSNSを設定 | URL取得を選ぶと同じ画面に選択欄が展開。[一覧](media.md) |
| ルール | 本文、詳細ルールのURL |
| 制限・連投対策 | 投稿間隔、通報通知人数、投稿数・文字数・同一本文の制限 |
| 匿名ID・保存期間 | ID表示、連続投稿のID保持時間、投稿・通報の保存期間 |
| 画像・動画の安全設定 | NSFW・NSFLを個別に許可。未選択は拒否 |
| 管理・投稿ロール | 管理ロール、投稿ロール、通報先、処置ログ先、通常投稿の許可 |
| 禁止語・ドメイン | 1行に1つ。禁止ドメインはサブドメインにも適用 |
| 書き出し／読み込み | 設定JSONの共有。Webhookなどの秘密情報は含めない |

URL取得だけを許可したチャンネルでは、「メッセージに返信」もURL入力フォームになります。確認画面で返信先を確認して送信できます。

## 主な初期値

| 項目 | 初期値・範囲 |
| --- | --- |
| 匿名ID | 表示、連続投稿の保持20分。保持時間は0〜1440分 |
| 投稿間隔 | 5秒。0〜3600秒 |
| 連投対策 | 60秒で5件、60秒で3,000文字、300秒で9,000文字 |
| 文字数超過 | 10分間の利用制限 |
| 同一本文 | 300秒間、同じ利用者の再投稿を禁止 |
| 通報通知 | 異なる通報者3人。1〜50人 |
| 投稿・通報の保存 | どちらも無期限 |
| NSFW・NSFL | どちらも拒否 |
| 通常投稿 | 新規セットアップでは削除・DM警告。2ページ目で許可に変更可能 |
| ルール | サーバーのルールに従ってご利用ください。 |

連投対策は同じサーバー内の匿名投稿チャンネルを合算し、投稿先の設定値で判定します。「制限・連投対策」→「連投対策」で変更でき、各上限・同一本文の禁止時間は0で無効化できます。件数超過は直近60秒の枠が空くまで、文字数超過は設定した時間だけ制限します。最短投稿間隔以外の理由・上限・残り時間は投稿者へ表示しません。

## 保存期間

| 設定値 | 動作 |
| --- | --- |
| `0` | 保存しない。既存の対象ログも削除 |
| 日数 | 投稿1〜90日、通報1〜180日 |
| `無期限` | 自動で期限切れにしない |

保存0では、本人編集・削除・通報・投稿者照会など、履歴が必要な機能は使えません。
連投対策用のHMAC識別子・時刻・文字数・本文照合値・制限期限は保存0でも短期保存し、期限後に削除します。ユーザーID・本文・投稿メッセージIDはこの集計に保存しません。Bot再起動後も制限は継続します。
画面の本人確認にもHMACを使います。保存0のエラー記録は種類・コード等とHMAC識別子だけに絞り、24時間で失効・削除します。保存0へ変更したチャンネルの従来の診断ログも削除します。
DBのログ削除ではDiscord上の投稿やバックアップは削除されません。

## 設定JSON

```json
{
  "version": 1,
  "settings": {
    "content": { "allowNsfw": true },
    "policy": { "cooldown": 10 }
  }
}
```

区分は `panel`・`content`・`identity`・`policy`・`moderation` です。
項目と許容範囲の定義は [config.ts](../../src/domain/config.ts) にあります。
`content.animation`・`video`・`maxFiles`・`maxFileMB` は保存形式にありますが、現在の投稿制限には使われていません。
実際の取得制限は[画像・動画の取得](media.md)を参照してください。

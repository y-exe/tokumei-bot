# 画像・動画の取得

[目次](../README.md)

## 対応する入力

| 入力元 | 取得方法 |
| --- | --- |
| 直接添付 | 投稿フォーム・`/image` |
| 画像・動画URL | 公開HTTPSの画像・動画ファイル |
| その他の公開ページ | gallery-dl対応サイトは本家の抽出処理を使用。未対応は本文画像・画像情報・動画タグから取得 |
| X / Twitter | FxTwitter・FixupX経由で公開投稿のメディアを取得 |
| Pixiv | 公式の作品情報API。R-18作品はCookieが必要 |
| Bluesky | 公開APIで投稿画像を取得 |
| Mastodon | 公開・未収載投稿のメディアを取得 |
| Misskey | 公開・ホーム投稿のファイルを取得 |
| TikTok・Instagram・Threads | Atmosphere API経由で取得 |

外部サービスの仕様や公開状態によって取得できない場合があります。
利用サイトは `/settings` の「投稿できる内容」でURL取得を選び、「送信できるSNSを設定」で選択します。
汎用取得は「直接URL・その他の公開ページ」で切り替えます。本文の大きな画像を優先し、`data-src`・`data-original`・`srcset`・`picture` にも対応します。本文画像が見つからなければページの代表画像を使います。広告・関連画像は除外を試みますが、推定なのでプレビューを確認してください。
ログイン必須・JavaScriptのみで生成・DRM・HLS配信は汎用取得の対象外です。画像・動画の安全設定は通常どおり適用します。
gallery-dlはURL抽出専用の別プロセスで1件ずつ実行し、最大11候補から先頭10件を添付します。抽出の上限は30秒で、安全判定の時間制限ではありません。未対応・URL抽出失敗時は汎用処理へ戻します。任意のサイトへの対応を保証するものではありません。

## 加工と制限

- JPEG・PNG・WebP・GIF・AVIFを扱い、静止画は1600×1600以内に縮小。
- SVG・PDF・TIFF・ImageMagick形式の画像デコードは無効化しています。
- 画像の位置情報等のメタデータを落とし、PNG・JPEGへ加工。
- アニメーションは保持。直接添付の非画像ファイルは原則そのまま添付。
- URL取得は実データが画像・動画のものだけを添付し、HTMLやJSONをファイルとして送らない。
- HTMLの解析は2MiBまで、リンクの探索は1段・最大20候補まで。スクリプトや埋め込みプレイヤーは実行しない。
- URL取得は先頭10ファイルまで、1ファイル25MiB以内。低水準のダウンロード上限は32MiB。
- 元画像と加工後を合わせて1投稿32MiBまで。プレビューはBot全体で64MiBまで保持する。
- 原寸画像を[安全判定](media-safety.md)してから加工し、送信時にも現在の設定を確認。
- Xの動画は取得・安全判定後、動画リンクとして扱う。
- その他の対応サイト・直接URL・添付の動画も、長さに応じて1〜3コマを[安全判定](media-safety.md)する。Blueskyの投稿URLは画像のみ対応。

内部IP・非HTTPS・認証情報付きURLは拒否します。
DNS応答を確認したIPへ接続し、転送先も同じ基準で検査します。
公開ドメインのDNS検索には末尾の `.` を付け、内部用検索ドメインの付加を防ぎます。
NSFW・NSFL判定はウイルス検査ではありません。一般ファイルの直接添付はそのまま転送されるため、受信したファイルを開く際の安全性まで保証しません。

## Pixivのログイン

1. 使うアカウントでPixivへログインする。
2. ブラウザーの開発者ツールで「Application → Cookies → www.pixiv.net」を開く。
3. `PHPSESSID` の値を `PIXIV_PHPSESSID` に設定し、Botを再起動する。

CookieはPixiv公式の作品情報取得にだけ使用します。画像配信先や他サイトには送りません。
本番ではSecretに保存し、Git・チャット・ログへ値を残さないでください。
ログインが無効になった場合は同じ手順で更新します。

R-18作品を取得できても、投稿先でNSFWが拒否されていれば投稿できません。

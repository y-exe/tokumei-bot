# 使い方

[目次](../README.md)

## 投稿の流れ

1. チャンネルの案内で「匿名メッセージ送信」「画像送信」「URLから画像送信」を選ぶ。
2. 内容を入力して送信する。URL取得ではプレビューで添付対象を確認してから送信する。
3. 返信・編集・削除は投稿の操作、またはメッセージの「アプリ」から行う。

自分の保存期間内の投稿は `/mine` でも確認できます。
本文中の `>>番号` は、対応する投稿が見つかればリンクになります。
本文は1800文字までで、メンションは使えません。

禁止語で止まった場合は該当語を表示します。「文字を編集」で入力済みの本文を開き直すか、「禁止用語を伏字して再送信」で `改造` → `＊＊` のように置き換えてやり直せます。伏字はDiscordの太字にならない全角の記号です。投稿後の編集や画像説明文の変更も同じです。ボタンは本人だけが10分間使え、やり直す際も最新の設定で確認します。

## 初期セットアップ

`/setup` を実行して、次の3ページで設定します。モード引数は不要です。

1. メッセージ・ファイル・URL取得から使う機能を選ぶ。
2. 通常投稿の許可と、NSFW・NSFLの制限を決める。
3. プレビューを確認して「この内容で設置」を押す。

初期選択はメッセージ・ファイル送信が有効、URL取得は無効です。通常投稿・NSFW・NSFLは拒否です。URL取得を選ぶとファイル送信も有効にします。
細かな調整は確認ページの「詳細設定」、設置後は `/settings` から行えます。既存のチャンネル設定は自動変更しません。
URL取得が有効ならSNSの選択欄が同じページに表示されます。各ページの上部に公開案内のプレビューを表示します。
匿名IDは連続投稿のまとまりを示す番号で、恒久的な個人識別子ではありません。

## スラッシュコマンド

| コマンド | 用途 | 権限 |
| --- | --- | --- |
| `/post text:` | 文章を投稿 | 投稿者 |
| `/image file: text:` | ファイルを添付して投稿 | 投稿者 |
| `/url link: text:` | URLから画像・動画を取得 | 投稿者 |
| `/mine` | 自分の投稿を確認・編集・削除 | 投稿者 |
| `/help` | 現在のルールと使い方 | 利用者 |
| `/setup` | ページ式の初期設定で設置 | 管理 |
| `/settings scope:` | チャンネル・サーバー標準の設定 | 管理 |
| `/reports` | チャンネルの未対応通報 | 管理 |
| `/stop` | 匿名投稿の受付を停止 | 管理 |
| `/panel` | 案内の復元・位置の確認 | 管理 |
| `/error code:` | 保存されたエラー詳細を照会 | サーバー管理権限 |

`text:` などの項目はDiscordの入力欄です。添付・URLの説明文は任意です。
「管理」はサーバー管理権限、または設定した管理ロールを指します。
管理ロールへコマンドを公開する場合は、Discordの連携権限も確認してください。

## メッセージの「アプリ」メニュー

| 名前 | 用途 |
| --- | --- |
| メッセージに返信 | 指定した匿名投稿へ返信 |
| メッセージを編集 | 自分の匿名投稿を編集 |
| メッセージを削除 | 自分の匿名投稿を削除 |
| 匿名つぶやき通報 | 理由を付けて管理者へ通報 |
| 埋め込みを編集（Admin） | Botが設置した案内の設定を編集 |

保存しない設定では、履歴を使う編集・削除・通報を利用できません。
[保存期間の説明](settings.md)と[通報の説明](moderation.md)も参照してください。

## バグ報告

エラー画面の「バグを報告」からGitHubのフォームを開き、起きたことを入力して送信してください。操作・発生時刻・エラーIDが自動入力されます（IDがない案内では省略）。GitHubへのログインが必要で、送信前に内容を確認・編集できます。
エラーが出ない不具合は[バグ報告フォーム](https://github.com/y-exe/tokumei-bot/issues/new?template=bug-report.yml)から報告できます。報告は公開されるため、個人情報や非公開の投稿は載せないでください。

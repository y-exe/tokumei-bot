# 通報・モデレーション

[目次](../README.md)

## 通報の流れ

1. 管理者が `/settings` で通報先と通知人数を設定する。
2. 利用者が投稿の「匿名つぶやき通報」から理由を送る。
3. 異なる通報者が設定人数に達すると、通報先へ証拠と操作ボタンを送る。
4. 管理者が通知、または `/reports` から対応を選ぶ。

通報人数に達しただけでは処罰しません。
通知に失敗した通報は保存し、定期処理で再試行します。

## 対応の選択肢

| 対応 | 動作・条件 |
| --- | --- |
| サーバーBAN | Botと実行者の両方にBAN権限が必要 |
| 1ヶ月タイムアウト | 約28日。Botと実行者の両方にタイムアウト権限が必要 |
| 匿名要望の使用権剥奪 | 匿名要望モードでのみ選択可能 |
| 処罰なし | 対応済みとして記録 |

BAN・タイムアウトでは、元の投稿も削除を試みます。
対象とのロール順位など、Discordの権限制限も適用されます。
処罰後に履歴更新が失敗した場合は、二重実行せず表示された案内に従ってください。

## 表示する情報

- 管理者への通知：投稿の証拠、通報理由、通報者。
- 匿名投稿者のDiscordユーザーID：通報通知や通常の管理画面には表示しない。
- Bot管理者による投稿者照会：[lookup](../operations/lookup.md)を使用。

投稿・通報を保存しない設定では、通報に基づく処罰は利用できません。

## 通常のメッセージ投稿

匿名投稿ボタンを使わない通常投稿は、「管理・投稿ロール」で許可・削除を切り替えます。
削除する設定では投稿者へDMで案内します。DM拒否などで通知できない場合もあります。

サーバー管理権限・管理ロールのある人、Bot、Webhookの投稿は削除対象外です。
案内の再送は[設定](settings.md)の「表示・再送」で変更できます。

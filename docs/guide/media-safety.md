# 画像・動画の安全判定

[目次](../README.md) · [モデルの技術仕様](../development/models.md)

## 許可・拒否の設定

`/setup`・`/settings` →「画像・動画の安全設定」で、次のカテゴリを個別に許可します。
未選択と旧設定はどちらも拒否です。

| カテゴリ | 判定対象 |
| --- | --- |
| NSFW | 性器・女性の胸や乳首の露出 |
| NSFL | グロ・流血 |

腹・肩・下着などの露出だけでは拒否しない方針です。ただしモデルの誤検出・見逃しがあります。

## 判定の流れ

拒否されているカテゴリだけを検査します。NSFWを許可した場合はNSFL用の3分類モデルだけを実行し、両方を許可した場合は安全判定を省略します。

1. 3分類モデルでNSFLを確認する。
2. NudeNetで女性の胸・男女の性器の露出を検出する。信頼度0.5以上でNSFWとする。
3. NudeNetで検出されなければ二次元モデルを実行する。
4. 二次元モデルは0.238以上を候補とし、0.6以上ならNSFWとする。
5. 0.6未満は周辺を切り出し、同じ部位が再検出された場合だけNSFWとする。

切り出しは部位の長辺の8倍、160〜1216ピクセルの正方形です。
3分類モデルのNSFWスコアだけでは投稿を拒否しません。

## 対応範囲

| メディア | 検査 |
| --- | --- |
| 静止画像 | 投稿用に縮小する前の原寸画像 |
| GIF・アニメーションWebP | 先頭と約5秒ごとのフレーム |
| 動画 | FFmpegで先頭と約5秒ごとに抽出。1216×1216、最大10分 |
| 通常の非画像ファイル | 画像・動画の安全判定の対象外 |

動画の解析タイムアウトは長さに応じて120〜600秒です。
一般添付・画像URL・X動画を含め、送信前の現在設定で確認します。
加工後ファイルにはSHA-256・判定バージョン・検査済みカテゴリを結び付け、設定変更で検査が必要になった場合は再判定します。
安全判定が必要な場合、壊れた画像・動画、解析失敗、10分を超える動画は投稿できません。
5秒間の途中にある短い場面は検出できない場合があります。

## 実行環境

- CPU上の`onnxruntime-node`と`sharp`を使用。Python・判定用外部APIは不使用。
- 3モデルを起動時に一度だけロード。フレーム・推論は逐次処理。
- sharpのキャッシュ無効・並列数1。モデルロード・推論のRSSと時間をログへ記録。
- 二次元モデルは `ANIME_INFERENCE_THREADS=2` に変更可能。CPU上限も2コア以上にする。

判定API・前処理・配置方法は[モデル仕様](../development/models.md)、検証方法は[開発](../development/testing.md)を参照してください。
